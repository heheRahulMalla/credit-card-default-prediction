# Data

The source notebook loads the course-hosted credit-card default dataset:
https://webpages.charlotte.edu/mschuck1/classes/DTSC2301/Data/credit_card_defaults.csv

30,000 records, 25 original columns: ID, 23 predictors and the binary target. Data describe credit-card clients in Taiwan. The notebook also accepts `data/credit_card_defaults.csv` when supplied locally. Dataset bytes are not redistributed in this repository. Verify the original provider’s attribution and reuse terms before redistributing. The course URL has not been tested during this packaging pass; the decision-tree verification used the project’s Drive CSV.
